# ADR-0002: ユーザー認証に Amazon Cognito を採用する

## ステータス

承認

## コンテキスト

47log では、ユーザーごとに訪問状況を管理するため、ユーザー認証機能が必要である。
初期リリースでは Google アカウントによるサインインを提供する。

## 決定

ユーザー認証には Amazon Cognito を採用し、Google を外部 ID プロバイダーとして連携する。

## 理由

- Cognito は Google を含むソーシャル ID プロバイダーとの連携を公式にサポートしている。
- 認証フロー、トークン発行、セッション管理を Cognito に委譲できるため、認証機能を独自実装する量を削減できる。
- API の認可には Cognito の認可機構を利用し、アプリケーションで JWT 検証を独自実装する必要をなくせる。

## 影響

- Google OAuth のクライアント情報、Cognito のユーザープール、アプリクライアント、およびコールバック URL を設定する必要がある。
- 保護対象の API は Cognito と連携した認可機構で JWT を検証する。
- 将来、他の認証プロバイダーを追加する場合も Cognito を介して連携する。
