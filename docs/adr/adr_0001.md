# ADR-0001: データベースに DynamoDB を採用する

## ステータス

承認

## コンテキスト

47log では、都道府県マスタとユーザーの訪問状況を保存するデータベースが必要である。
現時点の機能では、複雑な JOIN、全文検索、集計などの高度なクエリは想定していない。

## 決定

データベースには Amazon DynamoDB を採用する。

## 理由

- DynamoDB は従量課金で利用でき、利用量が小さい段階では不要な固定費を抑えられるため、コストパフォーマンスを高めやすい。
- 現時点で必要なアクセスパターンは、都道府県および訪問状況の取得・登録・更新が中心であり、DynamoDB のキーアクセスに適している。
- 複雑な JOIN、検索、集計を現時点では行わないため、リレーショナルデータベースを採用する必要性は低い。

## 影響

- データモデルは、想定するアクセスパターンを基に設計する。
- 将来、複雑な JOIN、検索、集計が必要になった場合は、DynamoDB の設計見直しまたは別のデータストアの導入を検討する。
